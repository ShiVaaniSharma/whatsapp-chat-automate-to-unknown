# WhatsApp Number Adder

A React application to chat on WhatsApp without saving contact numbers, with built-in international number validation and checker.

Created by Shivani.

## Features

- **Direct Chat**: Open chats directly in WhatsApp mobile app or WhatsApp Web without saving the contact to your address book.
- **WhatsApp Number Checker**: Real-time validation and carrier series verification for 47+ countries (India, US/Canada, UK, UAE, Saudi Arabia, Pakistan, Bangladesh, Australia, Singapore, Brazil, etc.) plus international numbers.
- **Copy Direct Link**: Generate and copy direct shareable WhatsApp chat links (`wa.me` or `web.whatsapp.com`).
- **Dynamic Formatting & Hints**: Live digit counter, country-specific prefixes, character limit truncation, and leading-zero correction.
- **Responsive Layout**: Designed for mobile, tablet, and desktop viewports.

## Tech Stack

- React 19
- TypeScript
- Vite
